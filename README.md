# RemotePhone

基于 RustDesk 二开的**远程手机电话控制**产品。私域分发，不上架、不推广。

- **软件版**：普通手机装 APK（尽量 No Root）→ 控屏 + 触控 + 实时双向通话音频
- **硬件版**：预刷定制 ROM + 虚拟摄像头 HAL → 按单定制、零库存

> 核心商业逻辑：**卖点分层 = 开发攻克顺序**（控制 → 语音 → 变声 → 摄像头），**能卖哪层 = 哪层已做通**。

## 现在该做什么

**只做一件事：打开 P0 闸门。** 详见 [poc/README.md](./poc/README.md)。

```
B1 机型矩阵（3-5天，无依赖，今天就能开始）
  └→ B2 探针工具（1周）
       └→ B3 下行提取 ‖ B4 上行注入（1-2周，可并行）
            └→ B5 No Root 路径验证（1-2周）
```

P0 通了 → 全线铺开 A→B→C→D；P0 死了 → 降级卖 S1 控制版，A 阶段 8 项任务照样商业化。

**A 阶段可与 P0 并行**，因为它明确"不依赖 P0 音频即可售卖"——这是设计草稿里最聪明的一条。
