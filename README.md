# superphone

基于 RustDesk 二开的**远程手机电话控制**产品。私域分发，不上架、不推广。

- **软件版**：普通手机装 APK（尽量 No Root）→ 控屏 + 触控 + 实时双向通话音频
- **硬件版**：预刷定制 ROM + 虚拟摄像头 HAL → 按单定制、零库存

> **卖点分层 = 开发攻克顺序**（控制 → 语音 → 变声 → 摄像头），**能卖哪层 = 哪层已做通**。

## 开发四步

| 步骤 | 内容 | 对应任务 |
|---|---|---|
| 1 | 白标 + key 认证（打地基，留好接口缝） | A 阶段 8 项 + D1 接口预留 |
| 2 | 音频 | B 阶段 8 项（**P0 生死线**） |
| 3 | 中继变声 | C 阶段 |
| 4 | 摄像头（噱头，最后做） | D 阶段 |

步骤 1 完善后再进步骤 2，串行推进。摄像头接口在步骤 1 就预留，实现放最后。
